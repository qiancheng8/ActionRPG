    阶段三验收 · 三个要带走的

    • 顺着白线走主流程，遇到不懂的节点再看它的彩线从哪来、到哪去。
    • 编辑器五件套各管一摊：内容浏览器 / 关卡编辑器 / 细节面板 / 蓝图编辑器 / 数据资产编辑器。

    一个常见误区

    "看蓝图不顺眼就想全搬回 C++。" 逻辑骨架、性能敏感计算放 C++ 没错，但设计师要反复调的数值留在蓝图/数据资产里——常态是混合开发，全重写不是起手式。

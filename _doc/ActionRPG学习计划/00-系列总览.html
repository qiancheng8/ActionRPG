UE 基础系列 · 首页导航　|　面向写过 C++、但没正经做过 UE 正向开发的读者　|　本页用一张大关系图把八篇串成进阶链，每个节点可点进对应文章。

这是一套写给 C++ 程序员的 Unreal Engine 4.27 入门教程。载体是 Epic 官方的 ActionRPG 示例项目，一个能跑起来、能打包上手机的完整动作 RPG。

如果你写过 C++、但没正经做过 UE 正向开发，这套教程就是为你准备的。我们不从「什么是游戏引擎」这种地方讲起，而是直接拿你能读懂的 C++ 源码当抓手，一步步爬到蓝图、编辑器、技能系统这些 UE 特有的东西上。

官方文档在这里：dev.epicgames.com / ActionRPG（4.27）

怎么用这套教程

八篇按顺序读，每篇对应一个学习阶段，都有动手练习和验收清单。建议你边读边把项目跑起来，改一点、编译、看效果，光看不练在 UE 里很容易翻车。完整的进度规划和时间估算见上一级目录的 ActionRPG学习计划.md。

★ 学习方法闭环图

每一篇的正确打开方式都是同一个循环：先在 C++ 基类找锚点读懂能力 → 去蓝图看怎么装配 → 跑起来观察行为 → 改一点再回头验证。光看不练在 UE 里必翻车，这个闭环转起来，知识才真正落地。

学习方法闭环：C++ 基类 → 蓝图装配 → 运行观察 → 回头改（循环往复）
① 读 C++ 基类
在 Source/ 找 RPG*Base
看「定义了什么能力」
→基类是锚点
② 看蓝图装配
在 Content/ 找 BP_*
看「数据和调参怎么填」
→编译·运行
③ 运行观察
PIE 跑起来
看行为对不对、断点验证
↺改一点
回到 ①／②

关键心法：C++ 定义「能力」，蓝图装配「数据与调参」，运行时验证两者拼起来对不对。锚点找对，后面的 AssetManager、背包、GAS 才不会读得一头雾水。

目录 · 八个阶段

按顺序读，点卡片进入对应文章。每篇都配动手练习和验收清单。

阶段一环境与引擎心智模型
编译、打开、跑起来，建立 UObject / 反射 / GC / 宏 / 模块这套 UE 世界观。
阶段二基类与蓝图子类的分工
UE 最反直觉的一点：C++ 基类几乎不直接用，而是被蓝图继承后在配置里引用。读懂这条配置链，就拿到了全项目的钥匙。
阶段三蓝图与编辑器工作流
C++ 程序员最想跳过、却最该补的一课。学会读蓝图、用编辑器，打通 C++ 和蓝图的往返。
阶段四Asset Manager 与数据资产
物品怎么组织、怎么按需异步加载。动手加一个新物品类型，踩一遍「三处必须同步改」的坑。
阶段五背包与存档系统
背包数据存哪、谁是权威、怎么异步存档、怎么用 delegate 广播变化。
阶段六GameplayAbilities 技能系统最大难点 ★
全项目的核心和最大难点。从最好懂的伤害管线切入，一路讲到能力、效果、属性、标签和物品授予能力。最大的时间黑洞，别赶，该停就停。
阶段七UI、加载屏与异步
UMG 界面怎么随背包数据自动刷新，加载屏为什么要做成独立模块，移动端为什么离不开异步加载。
阶段八打包、平台与毕业项目
打一个真包出来，把前七篇的设计动机收束到「因为要上手机」。最后用「新增一件武器」的毕业项目串起全栈。

一句话路线图

环境跑通 → 看懂「基类被蓝图化」的架构 → 能读蓝图 → 数据资产 → 背包存档 → 啃下 GAS → UI 与异步 → 打包 + 毕业项目。

提醒　GAS（阶段六）是最大的时间黑洞，别赶，该停就停。其余阶段都比它轻松。
